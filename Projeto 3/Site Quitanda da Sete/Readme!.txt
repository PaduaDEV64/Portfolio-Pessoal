## 💻 Sobre o Projeto
Este site foi projetado para ampliar o alcance da loja para mais pessoas fora as redes sociais, e ter um "catalogo" digital . O foco principal do desenvolvimento foi criar uma solução rápida, intuitiva e funcional para o dia a dia da quitanda.

## 📋 Contexto do Desenvolvimento
O projeto foi construído sob pedido da loja, sua versão inicial está funcional. Após a entrega das etapas principais e uma mudança de direção comercial por parte do contratante, o escopo foi encerrado antes da implantação final. O código foi mantido aqui para demonstrar a arquitetura aplicada e os desafios técnicos resolvidos durante o processo.
